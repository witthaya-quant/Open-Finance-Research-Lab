# Mathematical Formalization — Finite-Binomial American Put

**Case ID:** OFRL-CM-001-CS-002  
**Parent project:** OFRL-CM-001  
**Specification version:** 1.0.0  
**Last reviewed:** 2026-11-07  
**Status:** FORMALIZED FOR THE STATED RESEARCH MODEL  
**Implementation:** Case-specific Rust library under workbench/

## 1. Problem statement

Given a finite-horizon recombining binomial model for one underlying asset and a fixed-strike American put, determine:

1. The risk-neutral probability implied by the one-period no-arbitrage model.
2. The exact option value at every state of the lattice.
3. An optimal exercise/continue/indifferent decision at every non-terminal state.
4. The unique optimal value at time zero, while allowing for non-unique optimal stopping policies.
5. A certificate that can be checked independently against the model and its Bellman conditions.

The model is a deliberately bounded mathematical case. It does not represent a calibrated market process.

## 2. Assumptions and domain

Time is discrete and finite:

\[
t_n=n,\qquad n\in\{0,1,\ldots,N\}
\]

One period is the unit of time. The same factors apply in every period. There are no dividends or distributions.

The input parameters are:

| Symbol | Meaning | Domain |
|---|---|---|
| \(S_0\) | Initial underlying price | \(S_0>0\) |
| \(K\) | Put strike price | \(K>0\) |
| \(u\) | Up-state gross price multiplier per period | \(u>0\) |
| \(d\) | Down-state gross price multiplier per period | \(d>0\) |
| \(R\) | Risk-free gross accumulation factor per period | \(R>0\) |
| \(N\) | Number of periods to maturity | Integer, \(N\ge0\) |
| \(n\) | Current time index | \(0\le n\le N\) |
| \(j\) | Number of up moves by time \(n\) | Integer, \(0\le j\le n\) |

The strict no-arbitrage condition for the one-period two-state model is:

\[
0<d<R<u
\]

This ensures a unique risk-neutral probability strictly between zero and one. All quantities \(S_0,K,u,d,R\) are supplied as exact rational values. \(R\) is a gross per-period factor, not an annual percentage quoted without a time convention.

The model assumes a frictionless one-period bond with deterministic gross return \(R\), one risky underlying with two possible gross returns \(u,d\), and no dividends. Under this two-state, one-risky-asset model the market is complete for the one-period payoff space. The multi-period lattice applies the same transition and return assumptions at every step.

## 3. State process and risk-neutral measure

At each period, the underlying either moves up by factor \(u\) or down by factor \(d\):

\[
S_{n+1}=
\begin{cases}
uS_n & \text{with the up transition}\\
dS_n & \text{with the down transition}
\end{cases}
\]

The recombining state after \(n\) periods and \(j\) up moves is:

\[
S_{n,j}=S_0u^jd^{n-j}
\]

The risk-neutral up probability \(q\) is derived from the no-arbitrage martingale condition for the discounted underlying:

\[
q u+(1-q)d=R
\]

Solving for \(q\):

\[
q=\frac{R-d}{u-d}
\]

The down probability is:

\[
1-q=\frac{u-R}{u-d}
\]

Under \(0<d<R<u\), both probabilities are strictly between zero and one. \(q\) is a risk-neutral pricing probability implied by the model, not a forecast or a subjective real-world probability.

## 4. Payoff and exercise policy

The holder of the American put may exercise at any model time \(n\in\{0,\ldots,N\}\).

The immediate exercise payoff at stock price \(S\) is:

\[
g(S)=(K-S)^+=\max(K-S,0)
\]

At state \((n,j)\), the immediate exercise value is:

\[
E_{n,j}=g(S_{n,j})
\]

A stopping time \(\tau\) takes values in \(\{0,\ldots,N\}\) and is adapted to the information filtration generated by the observed up/down path. The holder seeks to maximize risk-neutral expected discounted payoff:

\[
V_{0,0}=\sup_{\tau\in\mathcal T_N}
\mathbb E^{\mathbb Q}\left[R^{-\tau}g(S_\tau)\right]
\]

where:

- \(\mathbb Q\) is the risk-neutral probability measure.
- \(\mathcal T_N\) is the set of stopping times bounded by maturity \(N\).
- \(S_\tau\) is the underlying price at the chosen exercise time.
- \(R^{-\tau}\) discounts the payoff to time zero.

This objective is an expected discounted payoff under the specified model. It is not an expected payoff under an investor's subjective probability measure.

## 5. Bellman recursion and acceptance predicate

At maturity there is no further exercise decision:

\[
V_{N,j}=E_{N,j}=\max(K-S_{N,j},0)
\]

At a non-terminal node, the continuation value is the discounted risk-neutral expectation of the two next-node values:

\[
C_{n,j}=
\frac{qV_{n+1,j+1}+(1-q)V_{n+1,j}}{R}
\]

The Bellman value is:

\[
\boxed{V_{n,j}=\max\left(E_{n,j},C_{n,j}\right)}
\]

The policy label is defined by exact comparison:

- Exercise if \(E_{n,j}>C_{n,j}\).
- Continue if \(E_{n,j}<C_{n,j}\).
- Indifferent if \(E_{n,j}=C_{n,j}\).
- Terminal at \(n=N\).

No epsilon or floating-point tolerance is used.

### 5.1 Correctness predicate

A valuation certificate is valid for model M if and only if all of the following hold:

1. It contains exactly \((N+1)(N+2)/2\) nodes, one for every pair \((n,j)\) with \(0\le j\le n\le N\).
2. Every node's time index, up-move count, underlying price and immediate payoff equal the model-derived values.
3. Every terminal node has value equal to immediate payoff and has no continuation value.
4. Every non-terminal node supplies the correctly recomputed continuation value from its two child values.
5. Every non-terminal node satisfies \(V_{n,j}\ge E_{n,j}\) and \(V_{n,j}\ge C_{n,j}\).
6. The recorded action attains the candidate value: exercise requires \(V=E\), continue requires \(V=C\), and indifferent requires \(V=E=C\).
7. The reported initial value equals the root node value.

These conditions are checked using exact rational equality and ordering. An implementation result that fails any condition is rejected, not rounded or coerced into a plausible output.

### 5.2 Why the certificate proves optimality

Define the discounted candidate value process \(X_n=R^{-n}V_{n,J_n}\), where \(J_n\) is the number of up moves by time n.

The Bellman dominance condition \(V_{n,j}\ge C_{n,j}\) implies that \(X_n\) is a supermartingale under Q. The exercise dominance condition \(V_{n,j}\ge g(S_{n,j})\) means that it dominates the discounted exercise reward at every time.

For any admissible stopping time tau, the finite-horizon optional-sampling inequality therefore gives:

\[
\mathbb E^{\mathbb Q}\left[R^{-\tau}g(S_\tau)\right]
\le V_{0,0}
\]

The recorded policy's equality/attainability condition chooses, at every reached non-terminal node, an action whose value equals the candidate Bellman value. It therefore attains the upper bound. This proves that the candidate root value is optimal for the stated finite model and that the recorded policy is an optimal policy.

The verifier checks the inequalities, terminal conditions, and attainability; it does not rely on the candidate generator's internal computation state. This is a model-specific certificate, not a claim about model calibration or market suitability.

## 6. Exact synthetic reference case

The case uses one fixed synthetic parameter tuple:

\[
S_0=100,\quad K=100,\quad u=\frac65,\quad d=\frac45,\quad R=\frac{21}{20},\quad N=3
\]

Therefore:

\[
q=\frac{\frac{21}{20}-\frac45}{\frac65-\frac45}
=\frac58,\qquad 1-q=\frac38
\]

The stock prices at maturity are:

| Up moves j | Exact S(3,j) | Put payoff E(3,j) |
|---:|---:|---:|
| 0 | 256/5 | 244/5 |
| 1 | 384/5 | 116/5 |
| 2 | 576/5 | 0 |
| 3 | 864/5 | 0 |

Backward induction gives the following selected decision nodes:

| Time n | Up moves j | Spot S(n,j) | Exercise E(n,j) | Continuation C(n,j) | Bellman decision |
|---:|---:|---:|---:|---:|---|
| 0 | 0 | 100 | 0 | 18325/2058 | Continue |
| 1 | 0 | 80 | 20 | 2615/147 | Exercise |
| 1 | 1 | 120 | 0 | 145/49 | Continue |
| 2 | 0 | 64 | 36 | 656/21 | Exercise |
| 2 | 1 | 96 | 4 | 58/7 | Continue |
| 2 | 2 | 144 | 0 | 0 | Indifferent |

The time-zero value is:

\[
\boxed{V_{0,0}=\frac{18325}{2058}\approx 8.9042759961}
\]

The decimal is presentation-only. The canonical computed value is the exact fraction.

## 7. Stopping-policy enumeration and non-uniqueness

There are two different finite policy spaces for N=3:

**Full-history stopping policies.** The non-recombining history tree has one root history, two histories at time 1, and four histories at time 2: seven non-terminal decision histories in total. A history-dependent stopping rule assigns an exercise/continue decision to each history, giving 2^7=128 policies. The eight terminal paths are the 2^3=8 up/down sequences.

**Recombining Markov-node policies.** The recombining lattice has six non-terminal state nodes across times 0, 1 and 2. A policy depending only on the current recombining state therefore has 2^6=64 assignments.

The two counts differ because the two distinct time-2 histories UD and DU recombine to the same state (2,1). Both policy classes are exhaustively enumerated on this reduced case. The exact maximum must equal 18325/2058 in both enumerations. The full-history policy space has eight maximizers; the state-based Markov policy space has four. These multiplicities reflect ties and alternative decisions. They do not imply multiple optimal option values.

## 8. Computational complexity and resource controls

The recombining lattice contains:

\[
M(N)=\sum_{n=0}^{N}(n+1)=\frac{(N+1)(N+2)}2
\]

Backward induction visits each node once and performs a constant number of rational operations per node, so the number of model-node operations is O(N^2). The first certificate retains every node, requiring O(N^2) node records in addition to the memory occupied by their exact rational values.

Big-integer arithmetic is not constant-time in bit length. The O(N^2) statement describes lattice-node operations, not a bit-complexity bound.

The API requires a caller-supplied maximum node count. Triangular node sizing uses checked integer arithmetic; a size overflow, a limit violation, or a fallible allocation failure returns a typed error before an answer is presented.

## 9. Assumption and limitation register

| ID | Assumption / limitation | Consequence |
|---|---|---|
| A-001 | No dividends or distributions | Early-exercise values are specific to a non-dividend-paying underlying |
| A-002 | Constant u,d,R per period | The initial model is time-homogeneous |
| A-003 | One underlying and one deterministic risk-free asset | Two-state one-period market is complete under the strict no-arbitrage condition |
| A-004 | Frictionless trading and no transaction costs, taxes, borrow costs or funding spreads | The model is not a transaction-level or net-of-cost valuation |
| A-005 | Finite discrete exercise dates at every model time | Continuous-time exercise and irregular Bermudan schedules are outside scope |
| A-006 | Synthetic inputs only | No market calibration, empirical fit, or forecast claim is made |
| A-007 | Exact rational arithmetic | Mathematical values are exact for this model; assumptions and economic specification can still be wrong |

Extensions to dividends, time-varying rates, time-varying up/down factors, discrete exercise schedules, or additional payoff types require a new model specification and tests before code changes.
